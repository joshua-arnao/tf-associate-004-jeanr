

## Provider Block
la configuración de los complementos (plugins) que Terraform necesita para comunicarse con las APIs de tus proveedores de nube o servicios

> features: Es obligatorio para Azure

> Descarga automática: Cuando escribes este bloque y ejecutas `terraform init, Terraform va a internet, busca el plugin oficial de Azure y lo descarga en una carpeta oculta (`.terraform/`)
